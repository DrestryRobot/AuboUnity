# AuboUnity

Unity digital-twin project for an AUBO i10 robot arm: kinematic solvers, imported
CAD models, and a TCP interface for exchanging data with an external controller.

## Overview

- **Editor version** — `2022.3.55f1c1`, recorded in
  `ProjectSettings/ProjectVersion.txt`.
- **Scene** — `Assets/AuboUnity/AuboUnity.unity`.
- **Scripts** (`Assets/AuboUnity/Script/`):
  - `FKSolver.cs` / `IKSolver.cs` — forward and inverse kinematics for the arm
  - `JointMove.cs`, `GunMove.cs`, `PoseInput.cs` — joint-driven and pose-driven
    motion, plus pose entry
  - `TcpServer.cs` — TCP endpoint used to exchange data with an external
    controller such as the robot program
  - `ColliderWarn.cs`, `AddMeshColliders.cs` — mesh collider generation and
    collision warning
  - `CameraSwitcher.cs`, `ViewControl.cs`, `ToggleUI.cs` — camera, view and UI
    control
- **Models** — `Assets/AuboUnity/Input/` holds the 3DS assets (`aubo_i10.3ds`,
  `desk*.3ds`, `workpiece*.3ds`, `source.3ds`, `digui.3ds`) and the Simulation
  (`*.sim`) scene files.
- **UI font** — TextMesh Pro with a Noto Sans SC font asset.
- **Packages** — see `Packages/manifest.json`: TextMesh Pro 3.0.7, Timeline
  1.7.6, uGUI 1.0.0 and Visual Scripting 1.9.4.
- **Third-party plugins** — `Plugins/RootMotion/` bundles the RootMotion
  FinalIK/Baker packages.

## Getting started

1. Install Unity `2022.3.55f1c1` through Unity Hub.
2. Add this folder as a project and open it; Unity regenerates `Library/`,
   `Temp/` and the IDE project files.
3. Open the scene `Assets/AuboUnity/AuboUnity.unity` and press Play.

`AuboUnity.sln` and `AuboUnity.csproj` are generated by Unity for Rider / Visual
Studio.

## Repository layout

| Path | Purpose |
| --- | --- |
| `Assets/AuboUnity/` | Scene, models, imported meshes and the C# scripts |
| `Assets/TextMesh Pro/` | TextMesh Pro assets and shaders |
| `Plugins/RootMotion/` | FinalIK / Baker third-party plugin |
| `Packages/manifest.json` | Package dependencies |
| `ProjectSettings/` | Unity project settings, including the editor version |

  is not covered by any licence of this project.
- Large binary assets (3DS models, `.sim` scenes, render textures) are committed
  directly, so the repository is relatively large and clones are slow.
